# EC2 배포 가이드

> EC2 한 대에 docker compose 로 올리는 구성입니다. 시연과 MVP 범위를 목표로 합니다.

```
EC2 (Ubuntu 22.04 이상)
  ├ nginx (frontend)  :80    정적 파일 + /api/v1 → backend 프록시
  ├ backend           :8080  Spring Boot (외부 비공개)
  ├ mysql             :3306  (외부 비공개)
  └ redis             :6379  (외부 비공개)
```

프론트가 `VITE_API_BASE_URL=/api/v1` 로 **같은 오리진**을 호출합니다. nginx 가 프록시하므로
브라우저 입장에서는 서버가 하나이고, **CORS 설정이 필요 없습니다.**

---

## 1. EC2 준비

### 인스턴스

| 항목 | 권장 |
|---|---|
| 타입 | `t3.small` 이상 (MySQL + JVM 이 같이 뜹니다. `t2.micro` 는 메모리가 부족합니다) |
| 스토리지 | 20GB 이상 |
| OS | Ubuntu 22.04 LTS |
| 서브넷 | **퍼블릭 서브넷** |

> ⚠️ **프라이빗 서브넷에 두려면 NAT 게이트웨이가 필요합니다.** 백엔드가 외부로 나가야
> 하는 곳이 많습니다 — 체인 RPC, 업비트 환율, SSAFY 금융망, 카카오페이. NAT 없이
> 프라이빗에 두면 결제·환불이 전부 타임아웃납니다.

### 보안 그룹 (인바운드)

| 포트 | 소스 | 용도 |
|---|---|---|
| 22 | **내 IP 만** | SSH |
| 80 | 0.0.0.0/0 | 서비스 |

**3306(MySQL)·6379(Redis)·8080(백엔드)은 열지 않습니다.** compose 네트워크 안에서만
접근하며, 열면 비밀번호 하나로 DB 전체가 인터넷에 노출됩니다.

아웃바운드는 기본값(전체 허용)이면 됩니다.

### Docker 설치

```bash
sudo apt-get update
sudo apt-get install -y docker.io docker-compose-plugin git
sudo usermod -aG docker $USER
# 로그아웃 후 다시 접속해야 docker 명령을 sudo 없이 쓸 수 있습니다.
```

## 2. 코드와 설정

```bash
git clone <저장소 주소>
cd S15P21B205
cp .env.prod.example .env
vi .env          # 값을 채웁니다
```

### 채워야 하는 값

| 변수 | 없으면 |
|---|---|
| `MYSQL_PASSWORD` `MYSQL_ROOT_PASSWORD` | DB 가 뜨지 않습니다 |
| `JWT_SECRET` | 로그인이 동작하지 않습니다. **32자 이상, 로컬과 다른 값** |
| `FRONTEND_BASE_URL` | 카카오페이 결제 후 돌아오지 못합니다. `http://<EC2 퍼블릭 IP>` |
| `SSAFY_API_KEY` | 회원가입 시 금융망 연동 실패 → **판매자 전환이 막힙니다** |
| `CRYPTO_RPC_URL` | **기본값이 일부 망에서 막힙니다.** 반드시 지정하세요 |
| `CHAIN_REFUND_WALLET_PRIVATE_KEY` | 코인 환불만 동작하지 않습니다(서버는 정상 기동) |
| `KAKAOPAY_SECRET_KEY` | 카카오페이 결제가 실패합니다 |

> **`CRYPTO_RPC_URL` 을 특히 확인하세요.** 기본값은 `rpc-amoy.polygon.technology` 인데
> 사내망 등에서 막히는 경우가 있습니다. 값이 없어도 **서버는 정상으로 뜨고**, 결제
> 단계에 가서야 "블록체인 노드 조회에 실패했습니다" 로 드러납니다.
>
> 검증된 값: `https://polygon-amoy-bor-rpc.publicnode.com`

### 🔴 개인키 취급

`CHAIN_REFUND_WALLET_PRIVATE_KEY` 를 가진 사람은 **그 지갑의 자산을 모두 옮길 수
있습니다.**

```
❌ user-data 스크립트에 평문      → EC2 콘솔에서 누구나 조회 가능
❌ docker-compose.yml 에 직접 기입 → git 에 올라감
❌ 채팅·이슈에 붙여넣기            → 영구 기록
✅ 서버의 .env (gitignore 대상)    → MVP 수준에서는 허용
✅ AWS Systems Manager Parameter Store (SecureString) + IAM 역할  ← 권장
```

**실서비스라면 Parameter Store 를 쓰고, 애플리케이션은 IAM 역할로 읽습니다.** 더 나아가면
KMS 나 외부 서명자에게 서명을 위임해 키가 애플리케이션 메모리에 올라오지 않게 합니다.

## 3. 실행

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

첫 빌드는 5~10분 걸립니다(Gradle 의존성 다운로드).

### 상태 확인

```bash
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f backend
```

### 기동 성공 기준

```
Flyway  Successfully validated N migrations
        Schema `gongguhan` is up to date
ChainTransferClient : 환불 지갑 준비됨 address=0x...
ChainClient         : 체인 클라이언트 초기화 chainId=80002 rpc=https://polygon-amoy-bor-rpc.publicnode.com
Started GongguhanApplication in N seconds
```

**`rpc=` 줄을 반드시 확인하세요.** 여기가 틀리면 결제·환불이 전부 실패합니다.

### 접속 확인

```bash
curl http://localhost/api/v1/actuator/health
# {"status":"UP"} 이면 정상
```

브라우저에서 `http://<EC2 퍼블릭 IP>` 로 접속합니다.

## 4. 시연 전 점검표

| # | 항목 | 확인 방법 |
|---|---|---|
| 1 | 회원가입 → SSAFY 연동 | `users.ssafy_user_key` 가 채워지는가 |
| 2 | 판매자 전환 (1원 인증) | `seller_profiles` 에 행이 생기는가 |
| 3 | 상품·공동구매 생성 | 화면에 목록이 뜨는가 |
| 4 | 카드 결제 | `payments.status = PAID` |
| 5 | **코인 결제** | MetaMask 버튼 → 확인 → 자동 입력 → 결제 완료 |
| 6 | **참여 취소 → 온체인 환불** | `refunds.status = COMPLETED` + tx_hash |
| 7 | 관리자 로그인 | `/auth/admins/login` |

### 코인 결제 시연 준비물

```
구매자 MetaMask 계정에
  POL   0.02 이상  (송금 1건에 약 0.0036)   ← faucet 에서 받습니다
  USDT  결제 금액 이상                        ← 컨트랙트 mint 로 채웁니다

MetaMask 에 Polygon Amoy 네트워크 등록
  네트워크 이름  Amoy
  RPC URL        https://polygon-amoy-bor-rpc.publicnode.com
  체인 ID        80002
  통화 기호      POL
```

> ⚠️ **MetaMask 의 RPC 도 공용 노드로 설정해야 합니다.** 기본값이 막힌 망에서는
> 잔액은 보이는데 송금만 실패합니다. 시연용 PC 를 미리 점검하세요.

## 5. 자주 겪는 문제

| 증상 | 원인 | 대응 |
|---|---|---|
| `Communications link failure` | MySQL 이 아직 기동 중 | `depends_on: healthy` 로 대기하지만, 첫 기동은 20초쯤 걸립니다 |
| `Port 8080 already in use` | 이전 컨테이너가 남음 | `docker compose -f docker-compose.prod.yml down` |
| 결제 시 "블록체인 노드 조회 실패" | `CRYPTO_RPC_URL` 미설정 | `.env` 확인 후 `up -d` 로 재기동 |
| 판매자 전환에서 "금융망 회원 연동 미완료" | `SSAFY_API_KEY` 미설정 | `.env` 확인. 기존 계정은 **재로그인하면 백필**됩니다 |
| MetaMask `gas tip cap below minimum` | 지갑이 이더리움 기준 수수료를 잡음 | 프론트가 30 gwei 를 명시합니다. 수동 송금 시에는 직접 지정 |
| 화면은 뜨는데 API 가 404 | nginx 프록시 경로 불일치 | `frontend/nginx.conf` 의 `/api/v1/` 확인 |

### 데이터 초기화

```bash
docker compose -f docker-compose.prod.yml down -v    # -v 는 DB 볼륨까지 삭제
```

⚠️ `-v` 는 **DB 를 완전히 지웁니다.** 코인 자산·지갑 설정(`crypto_assets`,
`crypto_wallets`)도 함께 사라지므로 재설정이 필요합니다.

## 6. 아직 하지 않은 것

MVP 범위에서 제외했습니다. 실서비스로 가려면 필요합니다.

| 항목 | 왜 필요한가 |
|---|---|
| HTTPS (ACM + ALB 또는 Let's Encrypt) | 지금은 HTTP 라 토큰이 평문으로 오갑니다 |
| CI/CD | 지금은 서버에서 직접 `git pull` + `up -d --build` 입니다 |
| 로그 수집 | 컨테이너를 내리면 로그가 사라집니다 |
| DB 백업 | 볼륨이 날아가면 복구할 수 없습니다 |
| 헬스체크 기반 무중단 배포 | 재배포 시 수십 초 끊깁니다 |
| 비밀값을 Parameter Store 로 | 지금은 서버의 `.env` 파일입니다 |
