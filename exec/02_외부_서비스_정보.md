# 공구한 외부 서비스 정보

키 값은 보안상 이 문서에 적지 않습니다. 설정 위치(환경변수)에 직접 넣어야 합니다.

## 1. SSAFY 교육용 금융망 API

- **주소**: `https://finopenapi.ssafy.io/ssafy/api/v1/edu` (`SSAFY_BASE_URL`)
- **가입**: SSAFY 금융망 개발자 사이트에서 팀 계정으로 로그인한 뒤 앱 등록 → **API Key** 발급
- **사용 API**
  - 사용자 계정 생성·조회 (이메일 기준 `userKey` 발급) — 회원가입 시 이메일 중복확인 단계에서 선점 확인
  - 수시입출금 계좌 개설, 신용카드 발급 — 가상 은행 콘솔 "카드 발급받기"
  - 카드 결제 승인 `createCreditCardTransaction`
  - 1원 송금 인증 — 판매자 전환 시 정산 계좌 확인
  - 계좌 이체 — 환불(플랫폼 → 구매자), 정산(플랫폼 → 판매자)
- **가맹점 ID**: V7 마이그레이션이 `platform_policies.SSAFY_MERCHANT_ID`에 시드합니다. 새 키로 바꾸면 `backend/scripts/ssafy-create-merchant.mjs`로 가맹점을 다시 등록합니다.
- **주의**
  - 요청 헤더의 전송 시각은 **KST**여야 합니다 (UTC이면 `H1003`).
  - 기관거래고유번호는 매 요청마다 새로 발급해야 합니다 (재사용 시 `H1007`).
  - 참고 문서: `docs/external/SSAFY_교육용_금융망_API+플로우.pdf`, `docs/external/SSAFY_교육용_금융망_API_Inferface_예제.xlsx`

## 2. 카카오페이 온라인 단건결제

- **가입**: [카카오페이 개발자센터](https://developers.kakaopay.com) 가입 → 애플리케이션 생성 → **Secret Key (dev)** 발급
- **설정**
  - `KAKAOPAY_BASE_URL=https://open-api.kakaopay.com`
  - `KAKAOPAY_CID=TC0ONETIME` (테스트 가맹점 코드, 실제 과금 없음)
  - `KAKAOPAY_SECRET_KEY=<Secret Key(dev)>`, `KAKAOPAY_AUTHORIZATION_SCHEME=SECRET_KEY`
  - `FRONTEND_BASE_URL=https://j15b205.p.ssafy.io` — 결제 후 돌아올 주소(`/checkout/kakaopay/success|cancel|fail`)의 기준
- **사용 API**: `/online/v1/payment/ready`, `/approve`, `/cancel`

## 3. Polygon Amoy 테스트넷 · MetaMask (코인 결제)

- **체인**: Polygon Amoy, chainId `80002`
- **RPC**: `https://polygon-amoy-bor-rpc.publicnode.com` (공식 RPC는 일부 망에서 차단되어 이 주소를 사용)
- **토큰**: 자체 배포한 ERC-20 테스트 USDT — 소스 `docs/contracts/GongguhanTestUSDT.sol`, 배포 가이드 `docs/contracts/README.md` (Remix로 배포)
- **준비물**
  1. MetaMask 설치 → Polygon Amoy 네트워크 추가
  2. Faucet에서 가스비용 **POL** 받기
  3. 테스트 USDT 컨트랙트 배포 후 구매자 지갑으로 토큰 발행
  4. 수취(RECEIVE) 지갑과 환불(REFUND) 지갑 주소를 `backend/scripts/seed-crypto-config.sql`로 DB에 등록
  5. 환불 지갑 개인키를 `CHAIN_REFUND_WALLET_PRIVATE_KEY`에 설정 (환불 지갑에는 POL과 USDT가 있어야 함)
- **필요 컨펌 수**: USDT 5회 (정책값, 관리자 "운영 정책 > 코인 결제"에서 변경 가능)

## 4. Upbit Open API (환율)

- 가입이나 키가 필요 없는 **공개 시세 API**입니다.
- `CRYPTO_EXCHANGE_BASE_URL=https://api.upbit.com`, `CRYPTO_EXCHANGE_MARKET=KRW-USDT`
- 조회 결과는 10초 동안 캐시합니다 (`CRYPTO_RATE_CACHE_TTL_MS`).

## 5. Google Cloud Vertex AI (Gemini)

- **가입**: Google Cloud 콘솔 → 프로젝트 생성 → **Vertex AI API** 사용 설정
- **인증**: 서비스 계정 생성 → 역할 **Vertex AI User** 부여 → JSON 키 발급 → 서버의 `deploy/secrets/gcp-sa.json`에 저장 (`chmod 644`)
- **설정** (`deploy/env/ai.env`): `GEMINI_PROJECT=<프로젝트 ID>`, `GEMINI_LOCATION=global`, `GEMINI_MODEL=gemini-3.8-flash`
- **용도**: 판매자 상품 등록 화면의 "AI로 정보 채우기" — 이미지로 상품명·브랜드·모델·카테고리·색상·설명 추출

## 6. AWS S3

- **가입**: AWS 콘솔 → S3 버킷 생성 (`gongguhan-product-images-dev`, 리전 `ap-northeast-2`)
- **IAM**: 해당 버킷에 대한 `s3:PutObject`, `s3:GetObject`, `s3:DeleteObject` 권한을 가진 사용자의 Access Key 발급
- **설정**: `AWS_S3_BUCKET`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, (선택) `AWS_S3_PUBLIC_BASE_URL`
- **로컬 개발**: S3 대신 MinIO를 씁니다 (`docker-compose.yml`, `AWS_S3_ENDPOINT=http://localhost:9000`, 버킷 `gongguhan-local`)

## 7. 주소 검색

- 다음(카카오) 우편번호 서비스 — 키가 필요 없습니다. 회원가입, 배송지, 판매자 반품지 입력의 "주소 검색" 버튼에서 사용합니다.
