| 구매자 계정 A | 가상 은행 콘솔에서 카드 발급을 마친 계정 (카드번호·CVC 메모) |

## 1. 서비스 소개 · 메인 화면 (구매자, 비로그인)

1. `https://j15b205.p.ssafy.io` 접속.
2. 히어로 문구 **"이거 어디서 샀어? / 이거 공구한 건데"**와 부제 "필요한 사람끼리 모여 더 싸게, 결제는 에스크로로 안전하게"를 소개.
3. 아래 **"지금 참여할 수 있는 공동구매"** 목록을 보여 줌.
4. 상단 메뉴 **"서비스 소개"** 클릭 → 서비스 개념 설명 후 돌아옴.

## 2. 회원가입 · 로그인

1. 우측 상단 **"로그인"** 클릭 → 로그인 화면 아래 "아직 계정이 없으신가요?"의 **"회원가입"** 클릭.
2. **계정 정보** 입력
   - "이메일" 입력 후 옆의 **"중복확인"** 클릭 → "사용할 수 있는 이메일입니다." 표시.
   - 공구한 가입 여부뿐 아니라 **SSAFY 금융망 계정 선점 여부까지** 확인한다고 설명.
   - "비밀번호", "닉네임", "휴대폰 번호" 입력.
3. **기본 배송지** 입력: "받는 사람", "받는 분 연락처" 입력 → **"주소 검색"** 클릭 → 주소 선택 → "상세 주소" 입력.
4. **"가입하기"** 클릭 → 로그인 화면에 "가입이 완료되었습니다" 표시.
5. "이메일", "비밀번호" 입력 후 **"로그인"** 클릭.
6. 로그인 후 메인에 **"회원님을 위한 공동구매"**(개인화 추천, 추천 사유 표시) 캐러셀이 나타나는 것을 보여 줌.
   - 행동 데이터가 있는 구매자 계정 A로 로그인해야 추천이 보임.

## 3. 판매자 — AI 상품 등록 · 공동구매 개설 (판매자 창)

1. 판매자 계정으로 로그인 → 상단 **"판매자센터"** 클릭.
   - 판매자가 아니면 `/seller/verify`로 이동. 필요하면 **"판매자 전환"** 과정 설명: "정산계좌 만들고 1원 인증 받기" → "1원 인증코드" 입력 → "확인" → 판매자 정보 입력 → "판매자로 전환하기".
2. 상단 **"상품 등록하기"** 클릭.
3. **"상품 이미지"** 영역에 대표 이미지를 끌어다 놓기.
4. **"AI 상품 정보 자동 추출"** 박스의 **"AI로 정보 채우기"** 클릭 → "분석 중…" 후 상품명·브랜드·모델명·카테고리·색상·상품 설명이 자동으로 채워짐 (Gemini).
5. "상품 가격" 입력 → **"상품 등록하고 공동구매 만들기"** 클릭.
6. 공동구매 생성 화면
   - **"모집 조건"**: "목표 모집 인원"(예: 3), "1인 배송비", "모집 기간"(일수 칩) 입력.
   - 오른쪽 **"금액 구성"**, **"예상 정산 · 전원 구매확정 기준"**이 실시간 계산되는 것을 보여 줌.
7. **"공동구매 생성하기"** 클릭.

## 4. 구매자 — 공동구매 참여 · 카드 결제 (구매자 A 창 + 은행 콘솔)

1. **은행 콘솔**에서 구매자 A로 로그인 → **"내 카드"**의 카드번호·CVC 확인 (발급 전이면 **"카드 발급받기"**, 계좌도 자동 개설).
2. 공구한 상단 **"공동구매"** → 방금 만든 공동구매 카드 클릭.
3. 상세 화면 설명: "1인 분담금", "+ 배송비 · 총 금액", 진행 바 "현재 n명 참여 / 목표 n명", "목표 인원 달성 시 결제가 확정됩니다 / 미달 시 결제는 자동 취소됩니다".
4. **"공동구매 참여하기"** 클릭.
5. **배송지 선택**: 기본 배송지 라디오 선택 → "배송 요청사항" 선택 → **"결제수단 선택하기"** 클릭.
6. **결제수단** 화면
   - 오른쪽 **"참여 자리 확보 중"** 타이머를 가리키며 설명: 결제 전에 **슬롯(자리)을 먼저 선점**하고, 5분 안에 결제하지 않으면 자리가 풀린다.
   - **"카드 결제"** 선택 → "카드번호", "유효기간", "CVC" 입력.
7. **"{금액} 결제하기"** 클릭 → "결제가 완료되었습니다" 화면.
   - "결제 금액은 구매확정 전까지 에스크로에 보관됩니다" 문구 강조.
8. **은행 콘솔** 새로고침 → **카드 이용내역에 방금 결제가 찍힌 것**을 보여 줌 (SSAFY 금융망 실제 반영).

## 5. 구매자 — 카카오페이 결제 (구매자 B 창)

1. 같은 공동구매 상세 → **"공동구매 참여하기"** → 배송지 선택 → **"결제수단 선택하기"**.
2. **"카카오페이"** 선택 → **"{금액} 결제하기"** 클릭.
3. 카카오페이 결제창(테스트)에서 결제 진행 → 공구한으로 돌아와 "결제 확인 중" → 결제 완료 화면.

## 6. 구매자 — 코인(USDT) 결제 (구매자 C 창, MetaMask)

1. 같은 공동구매 → 참여 → 배송지 → **"코인"** 선택.
2. **"결제할 코인"**에서 USDT 선택 → **"적용 환율 (Quote)"** 박스에 시장 환율·적용 환율·결제 수량·필요 컨펌·입금 주소가 표시됨 (업비트 실시간 환율).
3. **"MetaMask로 송금하기"** 클릭 → MetaMask 팝업에서 송금 승인 → "보내는 지갑 주소", "트랜잭션 해시"가 자동 입력됨.
4. **"{금액} 결제하기"** 클릭 → MetaMask **서명 요청**(지갑 소유 증명, 송금·토큰 승인 아님) 승인.
5. **"입금 확인"** 화면에서 "컨펌 n/5회"가 올라가는 것을 보여 줌 → 컨펌 충족 시 결제 완료.
   - 설명: 백엔드가 프론트의 해시를 믿지 않고 **체인 영수증을 직접 조회해 수취 주소·금액·송신자를 검증**한다.
6. 3명이 모두 결제하면 목표 인원 달성 → 공동구매 상태가 달성으로 바뀜.

## 7. 판매자 — 송장 등록 · 배송 처리 (판매자 창)

1. **"판매자센터"** → **"주문 관리"** 탭 → 공동구매 선택 → "참여자 주문" 표.
2. 행의 **"송장 등록"** 클릭 → "택배사", "송장번호", "발송일" 입력 → **"등록하기"**.
3. 일괄 상태 변경: **"전체 배송중으로"** → **"전체 변경"**, 이어서 **"전체 배송완료로"** → **"전체 변경"**.

## 8. 구매자 — 구매확정 · 반품 (구매자 창)

1. 상단 **"거래관리"** → **"참여 내역"** 탭 → 주문 펼치기.
   - 우측 **"나의 거래 현황"**의 "에스크로 보관" 금액을 보여 줌.
2. **구매확정**: **"구매확정하기"** 클릭 → 안내 체크박스 선택 → **"확인했습니다 · 구매확정"**.
3. **반품**(다른 구매자 계정): **"반품 신청"** → "반품 사유"(단순변심 / 상품 하자·오배송) 선택 → "상세 사유" 입력 → "예상 환불 금액" 확인 → **"반품 신청하기"**.
   - 판매자 창 **"반품 관리"** → **"반품 승인"** → **"수거 완료 확인"** → 환불 자동 실행.
   - 은행 콘솔 **계좌 거래내역에 환불 입금**이 찍힌 것을 보여 줌.
   - 설명: 카드 취소 API는 카드번호·CVC 재입력이 필요해서, 자동 환불은 SSAFY 계좌이체로 돌려준다.

## 9. 관리자 — 정산 · 환불 · 운영 (관리자 창)

1. `/admin/login` → "관리자 이메일", "비밀번호" 입력 → **"로그인"**.
2. **"대시보드"**: 플랫폼 책임 금액 / 보관 중 / 정산 대기 / 정산 완료 / 환불 KPI와 "처리 대기" 건수 설명.
   - (선택) **"모집 마감 판정"**의 **"배치 수동 실행"** → **"실행 확정"**으로 모집 마감 배치를 바로 돌려 보여 줌.
3. **"정산"** 탭 → "정산대기" 필터 → 정산 건 선택 → **"이체 실행"** → "실제로 돈이 나갑니다" 확인 → **"이체 실행"**.
   - 설명: 정산 배치(매일 03:00)는 지급 명세만 만들고, 실제 이체는 관리자가 확인한 뒤 실행한다.
   - 판매자 창 **"정산 관리"** 탭에서 정산 완료, 은행 콘솔에서 판매자 계좌 입금을 확인.
4. **"환불"** 탭: 실패 건이 있으면 **"재처리"** → **"재처리 실행"**.
5. **"운영 정책"** 탭: "결제 슬롯", "코인 결제", "수수료 · 인원" 등 정책값을 **"변경"** → **"저장"**으로 코드 수정 없이 바꿀 수 있음을 보여 줌.

## 10. (선택) 모집 실패 자동 환불

1. 목표 인원을 채우지 못한 공동구매를 미리 준비.
2. 관리자 대시보드 **"배치 수동 실행"** → 모집 실패 판정 → 참여자 전원 결제수단별로 자동 환불 (카드 → 계좌이체, 카카오페이 → 결제 취소, 코인 → 온체인 반환).
3. 구매자 **"거래관리" → "반품·환불"** 탭과 은행 콘솔에서 환불을 확인.
